## Note on filenames (archive edition)

To ensure this archive extracts cleanly on all operating systems — Windows in particular has a 260-character path limit — **309 PLAUD meditation filenames have been shortened for this archive** by stripping the redundant trailing suffixes:

- `-Public Spoken Word — PLAUD Note Prompt.md` → `.md`
- `-Public Spoken Word — PLAUD Note Prompt (1).md` → `.md`
- `-Public Spoken Word - Spirit-Led Scriptural Analysis & Content Template (1).md` → `.md`
- `-Continuous Life Block Discernment & First-Person Reflection Template.md` → `.md`

The **file content is unchanged** — every meditation still carries its full Encounter-Edition appendix with all 4,617 memo cross-references intact.

**About the memo: links inside files:** internal cross-references still point to the ORIGINAL long filenames (as they appear in Seth's vault). This is intentional — those links are the canonical addresses in the source vault. If you're reading this archive standalone (not inside the vault), the links will show the original paths but the target files inside this archive have shortened names. To resolve any link, ignore the trailing `-Public Spoken Word — PLAUD Note Prompt.md` suffix in the link — it will match a shortened `.md` file in the same folder.

Max path length in this archive: **198 characters** (previously 241) — safely within all common OS limits.
